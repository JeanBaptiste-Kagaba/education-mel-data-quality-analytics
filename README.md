# Education MEL Data Quality and Analytics

## Project Overview

This project demonstrates an end-to-end Education Monitoring, Evaluation, and Learning (MEL) data workflow, from data collection through KoboToolbox to data cleaning, SQL analysis, and Power BI reporting.

The objective is to improve data quality, summarize education indicators, and present findings that can support evidence-based monitoring and management decisions.

## Data Source and Preparation

The project uses education data collected through KoboToolbox. The collected data was processed using Python to identify and handle data-quality issues before the cleaned records were prepared for analysis.

The workflow includes:
- Data extraction and inspection.
- Data-quality checks and cleaning using Python.
- Preparation of cleaned data for analysis.
- SQL queries to examine indicators and compare district-level results.
- Power BI visualization and reporting.

## Tools Used

- **KoboToolbox:** Data collection.
- **Python:** Data cleaning and preparation.
- **SQLite / SQL:** Data analysis and aggregation.
- **Power BI:** Dashboard development and reporting.

## Analytical Focus

- Data completeness and quality.
- Education enrolment and attendance indicators.
- District-level comparisons.
- Identification of records requiring follow-up.
- Management summaries to support monitoring and decision-making.
